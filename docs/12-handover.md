## 2. دليل العميل — صفحة واحدة (اطبعها وعلّقها)

### مواقع الدخول

| الموقع | ماذا تفعل به | حسابه |
| :--- | :--- | :--- |
| `tedxalfalahyouth.sanity.studio` | إضافة المتحدثين والجلسات والرعاة | اسم المستخدم وكلمة المرور سُلّمتا مسبقًا |
| `webmail.hostinger.com` | قراءة والرد على رسائل البريد | `marhaba@` / `apply@` / `partners@` / `media@` — كلمات المرور سُلّمت مسبقًا |
| `tedxalfalahyouth.com` | التصفح فقط — لا يحتاج دخولًا | — |

### أين تصل الرسائل؟

| الصندوق | ماذا يصل إليه |
| :--- | :--- |
| `marhaba@` | كل ما يخص الحدث العام، والتواصل، والتطوع (Volunteering)، والاستفسارات العامة |
| `apply@` | إشعار كل طلب متحدث جديد (مع كامل بياناته — راجعها هنا) |
| `partners@` | الرعايات والشراكات (فورم Contact بكلمة Sponsorship + فورم Partner) |
| `media@` | الإعلام والصحافة |

> كلمة مرور كل صندوق سُلّمت سابقًا (WebMail — إن نسيتها، أبِدلها من hPanel أو راسل المطور).

### المهام الرئيسية الثلاثة

**1. إضافة محتوى (متحدث/جلسة/فعالية/راعٍ):**
- ادخل `tedxalfalahyouth.sanity.studio` → اختر النوع (مثل Speaker) → أنشئ جديدًا → املأ الحقول → فعّل **Published** → **Publish**. يظهر على الموقع خلال دقيقة.
- دليل الحقول كاملًا: `docs/04-content-management.md`.

**2. متابعة طلبات المتحدثين:**
- افتح `webmail.hostinger.com` ببريد `apply@` واطلع على إشعارات الطلبات الجديدة.
- و(عند تفعيل Google Sheets) افتح الـ Sheet لرؤية القائمة الكاملة بكل الحقول.

**3. الرد على استفسارات الجمهور:**
- افتح `marhaba@` يوميًا وأجب على الرسائل العامة (ردًا بالرد المباشر — عنوان البريد يظهر لك تلقائيًا).

## 4. خطة ما بعد التسليم (Roadmap)

### 4.1 إضافة دعم الفيديو (خطة مقترحة — نقلًا من `docs/04` §6)
1. **Sanity**: أضف حقل `videoUrl` (نوع `url`) إلى `speaker` و/أو نوع `session`.
2. **المحتوى**: أدخل رابط فيديو (YouTube/Vimeo) من Studio.
3. **الواجهة**: بطاقة المتحدث تُظهر غلاف الفيديو وتشغّله داخل `iframe` عند النقر.
4. **الاختبار**: تحقق من الفيديو في اللغةين ومن الأداء (نشر — اختبار — نشر).
> لم يُنفذ بعد؛ عند طلبه يُفتح برومبت تنفيذ مستقل.

### 4.2 تحديثات المحتوى (فريق المحتوى — دوري)
- متحدثون وجلسات وشركاء: عبر Sanity (إجازة دقيقة بعد Publish).
- النص الترحيبي والتواريخ (مثل موعد الحدث الظاهر): عبر ملفات `messages/` — مطور.
- بطاقة الفعاليات النشطة: إدارة من Sanity `eventInfo` (`showSpeakers`/`showSponsors`).

### 4.3 الصيانة الدورية
| المهمة | التكرار | المسؤول |
| :--- | :--- | :--- |
| تفقد `marhaba@` و`apply@` والرد | يوميًا | فريق الحدث |
| مراجعة سجلات الخادم (Hostinger) | أسبوعيًا | المطور |
| `npm audit` + ترقية تبعيات (`next@16.3.0` مستحبة) | شهريًا | المطور |
| مراجعة ميزانية/أداء GA4 | شهريًا | فريق الحدث |

### 4.4 ترقيات مستقبلية (مقترحات لنقاش لاحق — لا تنفيذ الآن)
- **مدوّنة/أخبار** على نفس الدومين (تأثير SEO قوي — مبنية على Sanity بسهولة).
- **بوابة شراء بديلة** بجانب Platinumlist (نظام دفع محلي أو عالمي — تكامل API جديد).
- **إعلانات / برنامج ولاء** للشركاء (صفحة شكر للرعاة أبرز وصور ديناميكية).
- **نشرة بريدية** (Opt-in عبر الفورمات الحالية — بشرط إضافة سياسة الخصوصية أولًا).
- **وايضًا قبل كل ذلك**: صفحتا **`/terms` و`/privacy` إلزاميتان للإطلاق** (غير موجودتين حاليًا — موثق في `docs/07` و`docs/11`).
