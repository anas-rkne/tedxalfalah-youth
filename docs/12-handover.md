## 4. خطة ما بعد التسليم (Roadmap)

### 4.1 إضافة دعم الفيديو (خطة مقترحة — نقلًا من `docs/04` §6)
1. **Sanity**: أضف حقل `videoUrl` (نوع `url`) إلى `speaker` و/أو نوع `session`.
2. **المحتوى**: أدخل رابط فيديو (YouTube/Vimeo) من Studio.
3. **الواجهة**: بطاقة المتحدث تُظهر غلاف الفيديو وتشغّله داخل `iframe` عند النقر.
4. **الاختبار**: تحقق من الفيديو في اللغةين ومن الأداء (نشر — اختبار — نشر).
> لم يُنفذ بعد؛ عند طلبه يُفتح برومبت تنفيذ مستقل.

### 4.2 تحديثات المحتوى (فريق المحتوى — دوري)
- متحدثون وجلسات وشركاء: عبر Sanity (إجازة دقيقة بعد Publish).
- النص الترحيبي والتواريخ (مثل موعد الحدث الظاهر): عبر ملفات `messages/` — مطور.
- بطاقة الفعاليات النشطة: إدارة من Sanity `eventInfo` (الأعلام الثلاثة `showSpeakers`/`showSponsors`/`showTeam` — **لقسم الرئيسية فقط**؛ الصفحات المستقلة مفتوحة دائمًا بحالة «قريبًا»).

### 4.3 الصيانة الدورية
| المهمة | التكرار | المسؤول |
| :--- | :--- | :--- |
| تفقد `marhaba@` و`apply@` والرد | يوميًا | فريق الحدث |
| مراجعة سجلات الخادم (Hostinger) | أسبوعيًا | المطور |
| `npm audit` + ترقية تبعيات (`next@16.3.0` مستحبة) | شهريًا | المطور |
| مراجعة ميزانية/أداء GA4 | شهريًا | فريق الحدث |

### 4.4 ترقيات مستقبلية (مقترحات لنقاش لاحق — لا تنفيذ الآن)
- **مدوّنة/أخبار** على نفس الدومين (تأثير SEO قوي — مبنية على Sanity بسهولة).
- **بوابة شراء بديلة** بجانب Platinumlist (نظام دفع محلي أو عالمي — تكامل API جديد).
- **إعلانات / برنامج ولاء** للشركاء (صفحة شكر للرعاة أبرز وصور ديناميكية).
- **نشرة بريدية** (Opt-in عبر الفورمات الحالية — بشرط إضافة سياسة الخصوصية أولًا).
- **وايضًا قبل كل ذلك**: صفحتا **`/terms` و`/privacy` إلزاميتان للإطلاق** (غير موجودتين حاليًا — موثق في `docs/07` و`docs/11`).
